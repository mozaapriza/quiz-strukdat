## Deskripsi Program
```
Soal 1 : Sistem Pengelolaan Nilai Mahasiswa
Program untuk mencatat data dan nilai mahasiswa menggunakan kombinasi Single Linked List dan Dynamic Array (vector). Di dalamnya terdapat algoritma Insertion Sort untuk
mengurutkan nilai, Linear Search untuk mencari mahasiswa berdasarkan NIM, serta Binary Search untuk mencari nilai pada data yang sudah urut.

Soal 2 : Sistem Antrean dan Pengelolaan Buku Perpustakaan
Program sederhana untuk simulasi peminjaman dan pengembalian buku di perpustakaan. Antrean peminjam diatur memakai Queue (FIFO),
riwayat pengembalian disimpan dengan Stack (LIFO), dan daftar ID buku dikelola lewat Binary Search Tree (BST) yang mendukung pencarian serta traversal Pre-Order, In-Order,
dan Post-Order.

Soal 3 : Sistem Pencarian Rute di Lingkungan Kampus
Program yang memetakan enam lokasi kampus (A sampai F) ke dalam bentuk Graph menggunakan Adjacency Matrix. Penelusuran lokasi dilakukan
dengan metode BFS dan DFS, sementara pencarian rute serta jarak terpendek antarlokasi dihitung menggunakan algoritma Dijkstra.

Soal 4 : Sistem Penglolaan Data Mahasiswa dengan Hash Table
Program penyimpanan data mahasiswa dengan NIM sebagai key dan nama sebagai value pada Hash Table berukuran 20. Penanganan tabrakan
data (collision) menerapkan metode Double Hashing, lengkap dengan operasi Insert, Search, Remove, dan Display.
```
## Cara Menjalankan Program
1. Buka terminal atau Command Prompt pada folder proyek ini.
2. Compile file C++ menggunakan `g++` (sesuaikan nama filenya):
```bash
g++ soal1.cpp -o soal1
Jalankan file hasil compile:

Windows: soal1.exe

Linux / Mac: ./soal1
```
